# Security

This repository publishes static design mockups only. It does not ship application
backends, API keys, or production credentials.

## Reporting a vulnerability

If you believe you have found a security issue related to materials in this
repository or their GitHub Pages deployment, please report it privately:

- Open a [GitHub Security Advisory](https://github.com/ParrloHQ/parrlo-mockups/security/advisories/new) for this repository, or
- Contact the repository maintainers via GitHub (`@MuratPod`).

Please do not open a public issue for sensitive reports.
