ДействиеЧто происходит
«Очистить историю»Диалог DP-3 → «Очистить» → история на телефоне удалена сразу → снекбар DP-4 (4 с). Сеть не нужна.
A · «Удалить мои данные»По erase-ui-text.md §7 и контракту POST /v1/me/erase: DP-5 → «Удалить» → DP-6 → сначала сервер, потом очистка телефона. 200 → DP-7 «Готово» со списками erased/kept; voice = pending_upstream → DP-7a «Принято»; 429 → DP-8b «через N», ничего не стираем; нет сети / 5xx → телефон очищаем, DP-8 «Серверные данные не удалены, повторите позже». Лимит — 10 раз в сутки.
Какой вариант показывать (RG)Не выбор дизайна, а флаг сервера: перед диалогом клиент смотрит /v1/config → features.erase. true → вариант A, false / неизвестно / нет сети → вариант B. Ответ 404 при A (флаг сменился) → как B: телефон очищен, сервер — по письму.
B · «Удалить данные на телефоне»DP-5 → «Удалить» → DP-6: стираем на телефоне историю, звук «Отправить голосом» и полученный файл → DP-7. Если что-то не удалилось → DP-7p (что осталось, «Повторить» — только остаток). Сеть не нужна. Данные на сервере — по запросу пользователя (контакт в Политике).
Перевод в облакеОдно согласие (VOICE_TEXT / NONE). Включён: статус «Включён» и «Выключить перевод в облаке» (подтверждение — как на экране согласия). Выключен: статус «Выключен», тап → экран согласия → после включения — обратно сюда, не в Настройки.
История выключена«Срок хранения» скрыт; при включении появляется со значением по умолчанию (30 дней).
Кнопки диалоговСправа: «Отмена» (основной цвет) и действие (цвет ошибки). При самом крупном шрифте — столбиком, действие сверху. Назад / тап по фону = «Отмена» (кроме DP-6).
