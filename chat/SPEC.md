# Parrlo Chat — дизайн-спецификация, фазы 1–2 (фаза 2 — §11, решения менеджера — §12) (онбординг + главный экран + образ Парло)

Версия макетов: 0.2 · 27.10.2026 (решения менеджера Chat внесены — см. §12). Приложение — **новое, отдельное от Parrlo Translate**.
Просмотр: `index.html` (RU/ES/EN, экран, устройство, размер). Живые кадры: `frames/{ru,es,en}-<экран>.html` (`?ann=1` — зоны камеры/сгиба Duo). PNG: `png/{ru,es,en}/<экран>/<устройство>-<размер>[-ann|-full].png`. Образы Парло: `persona/index.html`. Токены: `tokens.css`, компоненты: `components.css`, каталог: `COMPONENTS.md`. Правила Apple для витрины сайта: `APPLE-MARKETING-RULES.md`. Hero сайта (нейтральная рамка): `png/{ru,es,en}/hero/…` · `frames/*-hero.html`.

> **Что это не:** это не снимки с устройства. Макеты — HTML в Chrome со шрифтом Inter (экран-эмуляция Dynamic Type множителями), рендер PNG через Playwright. Реальный SF Pro, настоящие системные панели, Dynamic Island, система Liquid Glass и жесты на устройстве выглядят иначе; для сверки нужен прогон на iPhone/симуляторе.

## 1. Решение в 5–8 строк
1. Парло — один образ-«секретарь» (геометричный попугай по логотипу #00A86B/#FFC247), не «ИИ-иконка»: в онбординге он молчит и слушает, на главной — сверху списка как закреплённый «контакт-сцена» (одна кнопка), а чат с ним — обычная переписка с черновиками «Отправить / Изменить / Отмена».
2. Онбординг 6 шагов (точки 22×7 / 7×7, зазор 6): приветствие → язык → [вход, вне фазы 1] → **возраст (год рождения, до согласия)** → согласие → [настройка Парло, вне фазы 1]. Кадры: welcome, language, age, **отказ младше 16**, consent (+«Не сейчас»), отдельно «Мой голос»: 18+.
3. Согласие — отдельный экран: явная кнопка «Разрешить» (не отмечена заранее), рядом равнозначное «Не сейчас»; четыре коротких факта + необязательная «память» (выкл по умолчанию, рядом пометка, где её посмотреть и удалить). Юридические данные (оператор, ИИ-провайдеры, срок хранения) — помеченная заглушка «финализируют юристы». После «Не сейчас» — экран «Хорошо, без чтения чатов»: безопасный режим (всё через подтверждение) и одно мягкое напоминание через пару дней.
4. Главная: сцена Парло → список чатов → док (быстрые действия + поиск). Пустое состояние: Парло зовёт друзей по ссылке. На ≥600 — две панели «список | чат/Парло», на 1440 — с шириной списка 420.
5. Весь интерфейс — из одних токенов (`tokens.css`) и компонентов (`components.css`), пригодных для веба; брейкпоинты как контейнерные запросы; XL/AX5 схлопывают панели в одну и переносят слова с мягкими переносами.
6. Duo: закрыт = compact (с рейкой справа), раскрыт = regular (две панели), плюс две позы полураскрытия с зоной сгиба 40 pt без кнопок и текста. Геометрия — из стороннего источника, помечена как допущение.
7. Имя в латинице везде «Parrlo» (две r), в RU — «Парло». Языки RU («ты») / ES («tú») / EN, тексты с запретными фразами проверены автоматически.

## 5. Поведение
**Онбординг.** «Назад» всегда доступна (кроме первого шага); «Начать/Продолжить» всегда видны (прижаты к низу, тело скроллится под градиентом); на ≥600 — колонка по центру, действия сразу под телом. Язык: радио-список (RU/EN/ES), по умолчанию — язык системы. **Возраст (до согласия):** колесо «год рождения», документы не нужны; под колесом строка про «Мой голос» (только с 18 лет, отметка и условия — при включении). **Младше 16:** отдельный экран отказа без регистрации — спокойный заголовок «Пока не получится», «Аккаунт не создан», кнопка «Понятно» и мелкая ссылка «Указал не тот год? Изменить»; без колеса, без точек прогресса, без запугивания. **Согласие:** «Разрешить» → включает чтение чатов; «Не сейчас» → экран «Хорошо, без чтения чатов». Текст согласия скроллится, кнопки «Разрешить»/«Не сейчас» закреплены внизу. Переключатель «Запоминать мои предпочтения» выключен по умолчанию, под ним пометка «Посмотреть и удалить можно в Настройки → Парло → Память»; юр. блок (оператор, ИИ-провайдеры, срок хранения) — пунктирная заглушка. **После «Не сейчас» (безопасный режим):** работает всё по твоей просьбе, всё, что пишет Парло, уходит только после подтверждения; не работает — рассказ о новых сообщениях; плашка «Безопасный режим включён. Напоминание — когда и как часто: не утверждено» (решения по напоминанию нет, §12 п.7); «Всё же разрешить» ведёт обратно; включить можно в Настройки → Парло. **«Мой голос» (`voice-18`):** два чекбокса не отмечены заранее («Мне исполнилось 18 лет», «Я принимаю условия функции «Мой голос»»), «Продолжить» неактивна, пока не отмечены оба; ссылка «Читать условия»; документы не нужны; текст условий — заглушка.
**Главная.** Тап по сцене Парло → чат с Парло (стек на compact; на ≥600 — в правой панели). Тап по строке → чат. «+» — новый чат. Док: «быстрые действия» (лист/поповер: Новый чат, Позвонить, Продиктовать Парло, Пригласить по ссылке) и поиск. Пусто: приглашение по ссылке / поиск по имени.
**Чат с Парло.** Парло рассказывает «пока тебя не было», показывает черновики; отправка — только по тапу «Отправить»; ИИ-метка — только у сообщений, отправленных Парло без просмотра пользователем (подтверждённые черновики — без метки).
**Звонок.** Перед входом — явное согласие: текст уведомления + строка «Нажимая «Продолжить», ты соглашаешься на перевод и расшифровку этого звонка» и кнопка «Продолжить» от каждого участника (гость — то же самое); постоянный индикатор «Идёт расшифровка ИИ»; субтитры на языке слушателя с подписью говорящего и строкой перевода; протокол — лист/правая панель; кнопки: микрофон, завершить, протокол.
**Состояния кнопок:** normal / hover / pressed / focus / disabled — лист `states` на каждом языке.

## 6. VoiceOver / доступность
- Порядок чтения экрана: шапка (Назад) → прогресс («Шаг N из 6») → заголовок → содержимое → действия. Заголовки — `heading`.
- Сцена Парло: «Парло, ИИ-секретарь. 3 новых сообщения. Открыть» (`button`). Иконки: «Назад», «Новый чат», «Профиль», «Быстрые действия», «Поиск», «Продиктовать», «Протокол», «Выключить микрофон», «Завершить звонок».
- Строка чата: «Имя, превью, время, N непрочитанных» (сводная подпись), роль `button`; выбранная — «выбрано».
- Переключатель «Запоминать мои предпочтения»: «выключено / включено». Радио «Русский, выбрано».
- Индикатор записи: `status`, зачитывается при появлении. Субтитры: `aria-live="polite"` (не прерывать).
- Образы Парло — декор (`aria-hidden`), имя и статус говорит текст. Контраст и размеры — §7.
- Переносы: только мягкие, в XL/AX5; в ES/RU длинные слова проверены (§7).

## 7. Проверки (запускаются скриптами; результаты не публикуются)
Фактический прогон на **603 кадрах** (3 языка × экраны × устройства × размеры текста; 919 PNG, включая `-ann` и `-full`):
- **Слово шире строки / за краем экрана / блок за краем / горизонтальный скролл:** 0 нарушений, в том числе SE и Pro при AX5 (длинные слова ES/RU/EN: *conversaciones, конфиденциальности, предпочтения* — решены мягкими переносами в XL/AX5).
- **Тап-цели ≥ 44×44:** 0 нарушений (pressed-состояние со scale .96 не считается; переключатель — хит-область 44 по высоте).
- **Duo, зарезервированные зоны:** ни одной кнопки/текста/субтитров в зоне камеры/сгиба (проверка DOM по прямоугольникам, с учётом обрезки контейнерами).
- **Контраст, токены:** текст ≥ 4.5:1 (минимум 4.51: muted на glass, и белый на `--btn` 4.55), графика ≥ 3:1 (выкл-трек переключателя 3.45, фокус 7.3–8.1, активная точка 8.1).
- **Контраст, пиксели:** 5 420 надписей по скриншотам с невидимым текстом, ниже порога 0; минимальный запас +0.01 (подсказка «Поиск» на стекле, 4.51). Исключены надписи, перекрытые листом/скримом или обрезанные контейнером; отключённые кнопки не входят в требования WCAG.
- **Запретные фразы** («вашим голосом», always accurate, without errors, instant, AI magic, «словарь», AskErina, «Скоро»/Coming soon/Próximamente, конкуренты, wordmark капсом, числа-лимиты) в RU/ES/EN, i18n и HTML кадров: **0 совпадений** на 365 фрагментах.
- **Имя:** «Parrlo» (две r) в латинице везде; счётчик написания с одной r по проекту — **0**.
- Не проверено: реальные VoiceOver/Dynamic Type на устройстве; перенос слов в SF Pro (в макете Inter); скролл-позиции и анимации (статика).
- Известные ограничения макетов: на Pro при обычном размере экран «Согласие» скроллится (4 факта + «память» + политика не помещаются, «Разрешить/Не сейчас» всегда видны); полная версия — `png/*/ob-consent/{se,pro}-*-full.png`.

## 9. Ограничения и вопросы

### 11.2 Поведение (кратко)
- **Парло.** Тап по сцене → экран Парло (стек на compact; на ≥600 — правая панель). Голос: тап — запись, второй тап — «готово»; текст в поле, правит и отправляет человек. Чип подставляет просьбу в поле.
- **Черновик.** Единственная отправка — «Отправить». «Изменить» → правка в карточке; «Отмена» — закрыть без отправки. Подтверждённый черновик уходит **без метки ИИ**. Черновик сохраняется при сворачивании/сложении Duo.
- **Перевод.** Включён по умолчанию, показан на языке пользователя; оригинал — по кнопке у сообщения («Показать оригинал» / «Скрыть оригинал»). Отдельного переключателя перевода в шапке нет (решения нет — не утверждено). Для исходящих — подпись, на каком языке прочтёт собеседник.
- **Пометка ИИ.** Только у сообщений, отправленных Парло без просмотра пользователем; машиночитаемый флаг — в данных (`generated_by`, `reviewed_by_user`). У подтверждённых черновиков метки нет.
- **Звонок.** Перед входом — явное согласие: текст уведомления + строка «Нажимая «Продолжить», ты соглашаешься на перевод и расшифровку этого звонка» и кнопка «Продолжить» от каждого участника (гость — то же самое); в звонке — неснимаемый индикатор расшифровки; у вошедшего позже — то же уведомление и строка «кто присоединился»; после звонка протокол приходит в чат (карточка с «Открыть»). Кто может удалить протокол — не утверждено.
- **Лимиты.** Дневной и недельный; три группы — Парло, голос, звонки (отдельная полоска у каждой). Только полоски, без чисел остатка; размеры лимитов не называются; время сброса «09:00» — плейсхолдер «не утверждено». При исчерпании: полоска + время сброса + «Выбрать тариф»; обычные чаты, группы и перевод текста работают всегда (в группе и звонке то же, без цифр).
- **Незнакомец.** Первое сообщение: «Принять» и «Заблокировать»; до «Принять» Парло получателя сообщение не читает; под сообщением — строка возражения («Возразить» · «Подробнее»; рабочий путь — не утверждено). Для новых аккаунтов действуют лимиты (в интерфейсе не показываются, размер не определён).
- **«Не сейчас» → напоминание.** Только внутри приложения, не пушем. Остальное (когда, сколько раз, тексты) — решения нет: экран-заглушка, «не утверждено». Безопасный режим до решения пользователя.
- **Память.** Только с согласия; есть просмотр, удаление строки и всей памяти; вместе с памятью удаляются сводки, составленные по ней (юр. рамка). Состав памяти — «не утверждено» (записи-заглушки).
