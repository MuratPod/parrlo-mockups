# Parrlo Translate · гостевая страница по QR — элементы для Web App (макет v1)

Макет, не прод-код (v2). Открыть: `index.html` (слева панель: состояния, пара языков, рамка 360/390/430; на телефоне — кнопка «Макет» сверху; `?clean=1` скрывает панель). Все пути относительные, внешних зависимостей нет, шрифты лежат в `fonts/`. PNG: `png/web/{ru,es,en}/NN-состояние.png` (390×844 @2x), ширины 360/430/1440 — `png/web/widths/`, другие пары языков — `png/web/pairs/`.
Бренд v2.3, только тёмная тема. Фон `#12161C` + 3 небольших переливающихся пятна (медленный дрейф), при `prefers-reduced-motion` анимации выключены. Кнопка `#2BC48A` (текст `#0E1116`), перевод-облачко `#00875C` + белый текст, поверхность `#1C2026`/`#242B34`, знак-попугай `#00A86B` с клювом `#FFC247` (`mark.svg`), wordmark «Parrlo» — Nunito Black, «rr» зелёные (не капсом), интерфейс — Inter.

## 1. Принципы страницы
- Без регистрации, без настроек, без истории, без QR на странице. Одна кнопка записи + клавиатура как запасной путь.
- **Пара языков берётся из ссылки QR**, вручную гость её не меняет (как в iOS не добавляем новых механик): `?from=ru&to=es` — `from` = язык гостя (он же язык интерфейса), `to` = язык хозяина; поддерживаются ru / es / en, `from` ≠ `to`. В макете параметры работают (например `index.html?from=en&to=ru&s=reply`), панель только их переключает. Без параметров: язык интерфейса по `navigator.languages` (ru / es / en, иначе en), `to` по умолчанию: RU→ES, ES→RU, EN→ES. Пара показана чипом в шапке (не кнопка). `<html lang>` ставится по `from`.
- Ответ хозяина показывается в ленте так же, как «Собеседник» в iOS (слева, тёмные облачка: фраза хозяина на его языке и перевод для гостя); отдельных элементов управления для него на странице нет.
- Ничего не говорим о том, где и кем исполняется перевод/распознавание. Нигде нет чисел-лимитов.
- Запрещено в текстах: «вашим голосом», «всегда точно/без ошибок/мгновенно», «магия ИИ», «Для жизни в Испании», сравнения, «словарь», wordmark капсом, обещания о будущем запуске.

### Бейджи магазинов (макетные)
- Нарисованы по правилам использования: чёрная плашка, тонкая светло-серая обводка `#A6A6A6`, скругление 10, высота 56 (при высоте 56 ≥ минимума обоих магазинов), логотип слева с отступом ¼ высоты (14), две строки текста (мелкая «Загрузите в» / «Доступно в», крупная «App Store» / «Google Play»), пропорции ≈3:1 (App Store, 168×56) и ≈3,4:1 (Google Play, 189×56), охранное поле вокруг ≥ ¼ высоты (между бейджами 12 px), рисунок не растягивается.
- **⚠ В релизе заменить официальными ассетами с marketing-страниц Apple (Marketing Resources / Identity Guidelines) и Google (Google Play badge generator), локализованными ru/es/en. Официальные SVG/PNG в репозиторий не клали (лицензия), здесь только макетная имитация: шрифт Inter вместо фирменных, логотипы упрощены.**
- Google Play до запуска **неактивен и без какой-либо подписи о сроках**: кнопка `disabled` + `aria-disabled="true"`, серая, не кликается; `aria-label` — просто «Google Play», `title` нет. Формулировки о будущем запуске брендбук запрещает, поэтому ни на кнопке, ни в `aria-label`, ни в текстах их нет. К запуску станет активным (`<a href>` и обычный чёрный бейдж). Тексты бейджей на языке интерфейса.

Размеры: кнопка записи 62 px (капсула), зоны касания ≥44 px (проверено скриптом на всех состояниях), облачка: радиус 18, хвост 6, отступы 10/15/11/15 и 13/18/14/18; шапка: знак 32, чип пары 40, клавиатура 44.
Контраст текста ≥4,5:1 (перевод в облачке — крупный, ≥3:1, фактически 4,55). Для вторичного текста на фоне с пятнами взят `#B4BDC9` вместо `#9AA4B2` (иначе 4,3–4,4 над пятном).

## 4. Поведение для Web App
- **Запись:** тап → `getUserMedia` (по жесту, HTTPS) → кнопка «Готово» + живой текст; второй тап → конец. Облачко живой речи растёт, лента прокручивается вниз.
- **Обработка → перевод:** окно фразы (литературная форма появляется первой), затем анимация «Волна и искры» в облачке гостя и выезд перевода. При `prefers-reduced-motion`: без искр и блика, простая смена за 0,2 с, точки и ореол неподвижны.
- **Озвучка:** кнопка-динамик в облачке перевода (в макете только пульсирует).
- **Текстовый ввод:** отправка по ↑; при пустом поле кнопка неактивна; maxlength — по лимиту сервера (в макете не показан).
- **Ошибки:** микрофон → `err-mic` (текстовый вариант — основной кнопкой, «Открыть настройки» раскрывает подсказку, как разрешить микрофон в Safari/Chrome, потому что сайт сам настройки браузера открыть не может); сеть → `offline` (фраза сохраняется, «Повторить» отправляет снова); квота хозяина → `limit` (одна нейтральная формулировка для любой причины недоступности на стороне хозяина).
- **Скачать Parrlo:** показывается только после первого готового перевода, ненавязчиво (ссылка, не баннер). Android и прочие браузеры всегда видят эту веб-страницу; iPhone позже получит App Clip (карточка iOS появляется по тому же QR), веб остаётся запасным путём.
- **Не входит в макет:** реальные распознавание/перевод/озвучка, правка фразы касанием, «Неточно». Ручного выбора языка нет: пара приходит из QR.
