Parrlo — клавиатура «контекстный помощник»

Статичные макеты KB-Design-1 (волна 2). Только тёмная тема, демо-данные, без сети. Эталон: прототип #/kb2 и брендбук v2.3. Существующие экраны не изменены.

1. Клавиатура

Ряд контактов с меткой «угадано», кнопка «Parrlo ✨» / «Пишу…», чипы Короче / Мягче / Ещё вариант / Отменить, «Учтён ответ …» / «Не учитывать». Кнопки отправки в клавиатуре нет: отправка — штатной кнопкой мессенджера.

4. Тексты ошибок клавиатуры

Во всех случаях текст пользователя остаётся в поле — ничего не стирается. Тексты ошибок не содержат ни текста, ни переписки пользователя. Выберите язык.

5. Импорт переписки: нейтральное описание

Функция называется «Экспорт чата»: без логотипа и названия мессенджера в названии функции и иконке (иконка — нейтральный файл/архив). Обходов защищённых чатов (скриншоты, распознавание текста, массовое копирование) не предлагаем.
