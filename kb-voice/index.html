Голос в клавиатуре · первый выпуск

Макеты для parrlo-keyboard. Решения 13.11: диктовка на iOS — запись в приложении Parrlo Translate (вариант А); голос для голосовых — стандартный мужской / женский, без клона; распознавание — Soniox, регион ЕС. Распознавание идёт на сервере, не на устройстве. Демо-данные, без сети.

Каждый экран: светлая / тёмная тема, ru / es / en, обычный / самый крупный шрифт (×1.6 к базовому, панели клавиатуры ×1.25), малый / большой экран (iPhone SE 375×667 и Pro Max 440×956; Android 360×760 и 412×915). Переключатели — сверху. Нажмите на любой экран — откроются все 24 варианта сразу.

1. iOS · клавиатура

В расширении клавиатуры iOS нет микрофона: 🎤 открывает Parrlo Translate, запись идёт там. Назад в чат клавиатура вернуть не может — только системная «◀ <чат>» слева вверху, мы о ней подсказываем. Файл голосового — через системное «Поделиться».

2. iOS · Parrlo Translate · диктовка

H-D0 → системный запрос → H-D2 → H-D3 → H-D5 → H-D6 → «◀» → K-V2 «Вставить». Ошибки H-D7, прерывания H-D8.

3. iOS · Parrlo Translate · голосовое

🔊 → H-G0 → H-G1 → H-G2 → H-G3 → «Поделиться» (H-G4) → «Вернитесь в чат» → K-V5.

4. Android · голос в клавиатуре

На Android клавиатура пишет сама: все шаги — в панели клавиатуры поверх букв, без перехода в приложение. Экран раскрытия перед разрешением микрофона уже сделан (PR 486).

5. Android · клавиатура целиком и настройки

6. Тексты ru / es / en

Черновик. Согласие на голос проверит юрист. Регион ElevenLabs — скорее всего США (SCC), ждёт подтверждения; в тексте пока без региона. Ключи совпадают с файлом kb-voice/copy.js.

7. Иконки 🎤 / 🔊

Сетка 24, линия 2, скруглённые концы — как остальные иконки Parrlo. Цвет — основной зелёный темы (#00875C светлая / #2BC48A тёмная); выключенное состояние — 42% непрозрачности. SVG: mic.svg, voice.svg.

8. Схема (iOS)

Диктовка. Чат → клавиатура K-V0 → 🎤 → Parrlo (H-D0 один раз → микрофон) → H-D2 → H-D3 → H-D5 → H-D6 → «Готово» (подсказка «◀») → «◀ <чат>» → K-V2 «Вставить» → K-V3 (5 с «Вернуть как было») → обычный вид. Через 10 мин без вставки — K-V4.

Голосовое. Чат → 🔊 → Parrlo H-G0 → H-G1 (текст / перевод, голос) → H-G2 → H-G3 → «Поделиться» → чат в листе → H-G4b «Вернитесь в чат» → «◀» → K-V5.

Без доступа. Нет согласия / токена → K-V1a / K-V1c («Открыть» → Parrlo). Нет полного доступа → K-V1b (только путь в Настройках).

Данные. Аудио → сервер Parrlo → Soniox (ЕС); текст → Anthropic; озвучка → ElevenLabs. Аудио на сервере Parrlo не хранится. Ни одно обещание «на устройстве» в текстах не используется.
