# Parrlo — макет веб-демо (промежуточный)

Статичный **мок** веб-демо Parrlo («веб как iOS»). Это **не прод** и не реальное приложение: без бэкенда, без записи звука, только визуал и анимации.

Файлы: `index.html`, `mark.svg`, `fonts/` (Nunito, Inter). Все пути относительные.

## Режимы (параметр `?s=`)

- `?s=idle` — ожидание
- `?s=rec` — запись
- `?s=proc` — обработка
- `?s=done` — результат
- `?s=limit` — лимит
- `?s=app` — экран приложения
- `?s=morph&t=0.6` — морфинг-анимация, `t` — прогресс (например 0.3, 0.6, 1.0, 1.3)
